This is an R-based news recommendation project that generates a synthetic dataset of 400 news items and 1,500 users, builds and compares User-Based and Item-Based Collaborative Filtering models (UBCF and IBCF) using recommenderlab, and produces visualizations such as read-count distributions, user cosine-similarity heatmaps, profile-based recommendations, and a learning curve comparing Precision@5; to run it, open the .Rmd/.R script in RStudio, execute the code, and let the included check_and_install() function install required packages such as data.table, Matrix, recommenderlab, ggplot2, and reshape2.
